# The engine this bridge runs on

The editor SIED serves is [ranuts/document](https://github.com/ranuts/document) (AGPL-3.0), which
embeds the ONLYOFFICE editors (version 9.3.0.133). SIED uses it as received from this commit:

    ranuts/document @ 03e6b7cdee7a827fab57ec3e8bc9a69b0866f27e   (2026-10-15)

Compared file by file with that commit, SIED's copy differs only in these places. Every other
file of the engine, including all ONLYOFFICE files, is byte-identical.

| Path | What |
|---|---|
| `NOTICE` | Same file with two additions: a section describing SIED's modifications (this bridge), and the MIT notice for ranui and ranuts. A copy is in this folder. |
| `bin/vercel-postbuild.mjs` | Added by SIED. A small build step that decompresses the converter for hosts that re-compress. A copy is in this folder. |
| `public/**/*.html` (landing pages) | Generated by the engine's own build (`bin/build-pages.mjs`), not edited by hand. |

On top of that, the bridge in `../bridge/` is added to the editor page (`../depois-do-build.mjs`),
as described in the repository `README.md`.
